## 如何使用与判断

正式知识仍由仓库根目录的 YAML/CSV 维护。本目录的国内公告/投关/互动问答召回、海外关键词提取和 Gemini 摘要均是研究输入。公司自己的陈述不等于独立核验；关键词出现在风险提示或前瞻段落也可能被召回，不能据此认定产品已交付、供应关系成立或收入兑现。保留原始引语、来源、日期和 candidate/UNKNOWN 标记。

按日期先看汇总，再到国内或海外材料寻找具体来源。海外披露表的 disclosure_id 可联到主张、事件、证据表。跨日重复出现的候选保留各次观察，不能把各日报数量简单相加当成独立事件数。
