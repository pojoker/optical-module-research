# 光模块历史 Daily 入库复核

打开 [review.html](review.html) 按来源、观察日期、处置建议筛选，或直接搜索候选编号。展开「原文定位与历史观察日期」可查看保存的引语、原始链接、旧账本定位以及原件日期和本地观察日期。旧目标写「候选」「仅供定位」表示建议对照，不能据此改原条目。

如要逐条审核，可勾选编号复制给复核人，或下载 [review.csv](review.csv)，在 `review_decision` 与 `review_note` 写「批准／补证／驳回」、核实后的证据和指定目标。请保留稳定编号；表格与网页都不会写回知识库。实际入库由另一步执行，以逐条授权为准。

- 「待逐条复核」：有可定位内容和明确的复核方向，优先读原件。它不是“已核验”。
- 「待定位」「缺锚点」：先确认旧对象，或恢复/核对对应原件。
- 「仅作线索」：原件未提取到独立主张、技术关联不足、自动筛查触发，或来自未经核验的 Gemini 汇编。
- 公告入口不等于正文证据，投关提取文本不等于核对 PDF 页段；海外段号是采集定位，不是官方页码。

[coverage.json](coverage.json) 保存逐日覆盖和各来源的核对口径。扫描的是当前生产状态目录，截止 2026-11-09；没有补跑历史采集。没有产物的日期不等于没有更新。国内累计问答未找到可证明逐日归属的记录时保留日期未知；Gemini 纪要标注日期不能当成采集日期或披露日期。同一来源的重复观察不计为独立证据。
