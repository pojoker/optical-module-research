# 为什么前稿缺产品、内部实现又有大量 UNKNOWN

前稿存在整理错误。它把六家公司的一部分代表配置做成主稿，却没有先展开完整的资料内产品目录；还把八类环节固定初始化为空，再用“资料未披露”解释空值。旧28张卡的560条检查中，372条被标UNKNOWN，311条来自统一默认句，八类永不赋值的字段就占224条。这个数字反映抽取方式，不能用来判断厂商公开程度。

本次保留完整读过的原对话为问题线索，并逐项找回原厂依据。网页抽取遗漏不等于原厂没有资料；产品族路线已知也不应因为缺SKU而整项未知。以下原对话主张为便于核对的概括，不是逐字引语。

| 缺口类别 | 修订后的表达 | 例子 |
|---|---|---|
| 漏收产品、漏读规格 | 补回已披露内容，撤销对应未知 | 新易盛FR8、Coherent 2FR4 EML/PIN |
| 网页读取或动态内容漏取 | 标明提取方式问题并补原页内容 | Lumentum 1.6T CW DFB；光迅JS规格表 |
| 产品族已知、具体型号未对齐 | 同时列族级已知路线和型号级缺口 | Source 1.6T EML/SiPh/InP PIC变体 |
| 本稿未取得环节资料 | 标为未提取/待检索，不称厂商未披露 | PCB、载体、时钟等没有专项资料的项目 |
| 所核来源未写、或来源相互冲突 | 写清已读哪份资料、缺哪项或冲突何处 | 激光颗数、具体驱动料号；Source 2FR4距离冲突 |
| 功能不适用 | 不计成未知 | 铜缆AEC不涉及激光器或光电探测器 |

这次“补全”有两个可核对层次：当前三份公司清单的名称均有目录入口；六家公司新增核对的产品族和型号进入产品目录及逐项纠错表。它没有证明各公司所有定制SKU、全部内部BOM或所有量产状态已公开。

## 仍缺什么

当前资料只给公司角色或工艺能力的条目，仍缺具体产品目录；目录已有产品但没有规格书的，缺环节路线；环节路线已知的，可能仍缺器件型号、材料牌号、制造设备、测试条件和量产状态。各项放在公司目录与型号卡边界中，不再统一归为“内部实现未知”。

目标3仍须同速率、距离、温区、主机条件和误码率要求的对比资料。例如Lumentum的22W与16W是不同版本典型值，温区亦不同，不能直接把6W全部归因于TRO。目标4还需产品与实际工序、设备、材料、测试逐条关联；某设备商有相关设备，不等于已证明某模块采用它。

本轮按用户确认的范围归集现有资料全部公司：材料、芯片、器件、模块、设备、制造服务及相关系统/客户。全部公司目录逐名呈现产品与证据层级；保留原对话六家厂商的逐项纠错，并补入其他模块公司的产品族和具体配置。材料、芯片、器件、光引擎、设备与工艺/制造服务设有独立阅读入口；这些对象按自身功能记录，不套整模块20环节。目录归集完整不代表全部型号内部BOM完整。

## 先说这段对话能带来什么

已读完《用户提供的产品技术路线讨论》接口返回的全部 5 轮，包含双方正文；返回 hasMore=false、nextCursor=null。五轮问题依次为：主流厂商现有产品路线、主要技术分叉、明后年路线变化、路线不同造成的各环节变化、值得注意的问题。读取记录见同目录《对话读取记录.json》。引用在接口中呈现为占位符，没有给出对应网址；关键产品事实因此重新核对厂商原始资料。接口没有返回附件，正文也没有专利号或权利要求，不能据此声称读过专利评估报告或判断专利有效性。

| 对话内容 | 本次处理 | 放进初稿的方式 |
|---|---|---|
| 总速率、电通道、光通道分别记录 | 采用 | 型号卡分开标注；800G 等产品名中的名义速率与规格书含编码开销的线速不混用 |
| 光学实现、电处理架构、模块布局是不同维度 | 采用并细化 | 光源与调制拆开；不把“EML / 硅光 / LPO / CPO”排成互斥选项 |
| 用 20 个环节检查资料是否齐全 | 采用为检查清单 | 不把它当每款产品都具有的 20 个独立零件；集成、共用、不适用和未披露分别记录 |
| 路线变化会改变器件、封装、材料与测试 | 采用为后续研究问题 | 先记录具体产品实际公开的实现，再讨论变化机制；不自动推出用量、价值量或供应商受益 |
| 六家公司的具体产品配置 | 逐项重新核验 | 只把核到原始来源的配置列入已披露项；产品族、演示与型号分开 |
| SiPh 占比明显提高、2027–2028 形成某种格局 | 保留为待检验假设 | 产品数量和新闻数量不能代替收入或出货占比；未来路线另列，不填入当前产品 |
| 技术要求提高所以环节价值上升 | 不直接采用 | 还需要单件价格、数量、份额、良率、成本及采购证据 |
| 将价值量、用量、渗透率、份额、利润率再乘“良率/有效产能” | 不作计算公式 | 原式缺少统一计量口径，良率也可能已计入成本或有效产能；仅保留这些变量作为提问线索 |

原对话还有几处需要修正。EML 是带电吸收调制的激光器，硅光是集成平台，薄膜铌酸锂是调制材料；应记录实际发光和调制路径。芯片装在载体上、金丝键合、倒装焊和使用中介层也不是四选一。波导阵列光栅（AWG）与平面光波导平台（PLC）存在包含关系；PIN/APD 是探测器结构，InGaAs/Ge 是材料，不能放在同一互斥分类列。

同样，不能从“硅光”补写该产品必有片上波分复用器和锗探测器，也不能从“CPO”补写前面板光接口必然消失。对话中的“800G LPO：8×100G 电侧到 4×200G 光侧”没有提供如何转换通道的产品证据，本稿不采用这一组合。

## 这一稿怎样读

先看一个已能落到具体型号的例子：光迅 RTXM600-201 的发送路径已披露为“8×100G 电接口 → 重定时 → 1310nm EML 发射 → MPO-16 接口 → 500m 单模链路”。驱动芯片、内部耦合和接收 PD/TIA 的当前规格仍待补。路径中的箭头表示功能顺序，不代表已取得内部布线或完整物料表。[光迅产品页](https://www.accelink.com/en/lighting_your_dreams/1745716334399913986.html)

再看同一公司不同版本：光迅 RTXM700-200 披露制冷 EML 和 16×100G 电侧，RTXM700-502 披露硅光发射，后者当前页面未披露 DSP；不能把另一次展会的“3nm DSP”自动移到该 SKU。Lumentum 两款 1.6T 2×DR4 则都披露硅光，但电处理分别是完整收发重定时和仅发送端重定时。这正是将光学实现、电处理与产品版本分开后，能得到的具体答案。[光迅 EML 型号](https://www.accelink.com/en/lighting_your_dreams/1729755138554798081.html)、[光迅硅光型号](https://www.accelink.com/en/lighting_your_dreams/1859158602116268033.html)、[Lumentum 完整重定时](https://www.lumentum.com/en/products/16t-2dr4-osfp-transceiver-module)、[Lumentum TRO](https://www.lumentum.com/products/16t-2dr4-tro-osfp-transceiver-module)

先看产品总表，按公司和产品选择一张卡片，再展开各环节。卡片中的“已披露”仅指该项能在所列厂商资料找到，不表示第三方验证了性能，也不表示有规模出货。某环节区分“本稿待提取”“所核来源未列”“产品族与型号待对齐”“来源冲突”和“不适用”；已知部分保留在同条，不用一个UNKNOWN覆盖。

读一款产品时，先沿信号路径走：主机电信号进入模块 → 电信号处理与驱动 → 产生并调制光 → 光路与接口 → 对端接收；接收方向则是入射光 → 探测器 → 接收放大与电处理 → 主机。控制、电源、时钟、载体、散热和外壳支撑这条路径。这个阅读顺序不代表每种架构都有相同的独立芯片或相同布局。

术语：DSP 为数字信号处理芯片；重定时是恢复并重新输出信号时序。LPO 为线性可插拔光学架构；TRO 为仅发射端重定时。CW 为连续波光源；SiPh 为硅光；PIC 为光子集成电路；PD 为光电探测器；TIA 为跨阻放大器，将探测器输出的电流转换为电压；MUX/DEMUX 为合波/分波。OSFP、QSFP-DD 是模块封装形态；MPO、LC 是光接口类型。

资料采用两个独立标签。来源标签区分“厂商型号规格”“厂商产品族/公告”“现有账本摘录待回原文”“对话线索”；判断标签区分“直接披露”“部分披露”“工程推断”“待提取/检索”“所核来源未列”“冲突”和“不适用”。现有账本的原证据等级保留在索引内，不重新命名或提升。发布时间、版本时间、事实适用期、核对日期也分开；网页没有日期时明确写日期未标。

## 各环节检查清单

| 环节 | 要记录的实际问题 | 最容易误填的地方 |
|---|---|---|
| 01 主机电接口 | 通道数、每通道线速、调制、接口规范 | 把 800G 总速率当成每通道速率 |
| 02 PCB 与电连接 | 板材、走线、连接器和损耗预算 | 由高速率直接猜材料牌号 |
| 03 电处理 | DSP/重定时/通道转换；发送和接收分别说明 | 将通道数相同等同于没有 DSP |
| 04 驱动 | 调制器/激光器驱动、通道、集成位置 | 根据 DSP 型号猜驱动必然集成 |
| 05 发光与调制 | 光源类型/波长、调制器、集成平台 | 把光源材料与平台作为同级路线 |
| 06 载体与芯片互连 | 载体、中介层、焊线/倒装、材料 | 把不同层级封装工艺当互斥选项 |
| 07 发射耦合 | 光从芯片到光纤或下一光学元件的方式 | 从“硅光”直接猜边缘耦合或光栅耦合 |
| 08 合波 | 是否波分、波长组、器件、集成位置 | DR 并行链路套用 FR 波分结构 |
| 09 外部光接口 | 光纤、端口、连接器及距离 | 接口相同就认为内部结构相同 |
| 10 分波 | 接收侧分波实现与位置 | 有波分功能就猜 AWG 或薄膜滤光片 |
| 11 接收耦合 | 光进入探测器的路径 | 从发射耦合方式推定接收相同 |
| 12 探测器 | 结构、材料、通道、是否集成 | PIN、APD、Ge 三选一 |
| 13 接收放大 | TIA、线性/限幅、通道、集成位置 | 把 TIA 本身称为重定时芯片 |
| 14 控制 | MCU、诊断与管理接口 | 看到管理规范就猜 MCU 型号 |
| 15 非易失存储 | 参数存储及其独立/集成位置 | 未披露就填“无” |
| 16 电源 | 电压、电源管理、调谐/激光供电 | 从总功耗猜各部分分摊 |
| 17 时钟 | 时钟恢复、参考时钟与位置 | 假设一定存在独立时钟器件 |
| 18 无源电子件 | 匹配、滤波等具体配置 | 根据功能列出未经披露的 BOM |
| 19 热管理 | 功耗口径、温区、散热结构 | 把典型功耗与最大功耗直接比较 |
| 20 总体封装 | 可插拔/NPO/CPO、封装尺寸与布局 | 将演示平台当现售模块 |

材料、设备、工序和测试是贯穿上述环节的另一张关系表，不能简单当“第 21 个零件”。本稿记录明确披露的个别工艺，其余作为目标 4 缺口。

## 对原标注标准的具体补充

保留你提出的产能、供需、价格、订单等字段，但每条记录先明确“说的是谁的什么对象”。目标 2 所需的最小单位为：公司＋产品/版本＋环节＋一条主张＋来源锚点。同一篇资料可以拆出多条记录；同一产品也可以对应多篇来源。

需要增加：对象层级（整模块/光引擎/芯片/器件/材料/设备）、精确型号或产品族边界、应用和距离、电/光通道、发送/接收方向、环节、功能实现、独立/集成位置、采用状态、产品成熟阶段、事实适用期、核对日期、原文定位、未知原因。具体供应商、材料、设备和测试条件只有直接证据才填；没有证据就保持 UNKNOWN。

“当前产能/有效产能/利用率”等还需单位、地点、产品范围、期间和定义。公司级毛利率不能填入某型号；企业整体量产不能替代新产品已量产；新闻中的可供货不能替代客户部署。每个单元格可关联独立来源，不以整行最高等级覆盖全部字段。

| P0 | 已找回部分Driver/TIA/PD结构，但具体料号、PD材料、耦合与MUX器件工艺仍多待补 | 各产品的已知深度不同，不能一概称厂商未披露 | 原厂框图、封装剖面、技术白皮书、明确型号的拆解或测试报告 |
| P1 | PCB、电源、控制、存储、时钟、散热的具体实现 | 20 环节里支持功能仍大片未知 | 模块硬件资料、产品手册、可靠性报告 |

| P1 | 工艺对应的设备型号、材料牌号、供应商和连接参数 | 不能完成目标 4 的制造和测试链 | 实际工艺流程、设备应用说明、采购/供应关系与测试程序 |

| P2 | 型号级产能、订单、ASP、利用率、库存与未来占比 | 技术实现不能直接变成供需或利润判断 | 分产品经营披露及有口径的测算假设 |

未披露、尚未检索、来源访问失败、产品边界不清和不适用是不同缺口。初稿逐项保留原因；后续补资料时应优先解决产品身份和采用状态，再补内部环节，最后进行目标 3 的性能与经济性比较。

本轮遇到的具体资料问题也已保留：Coherent FTCE4527E1PxM 的网页写 MPO12，规格书写 MPO-16；Source 的 SPQ-HE2-8FO-COD 页面标题为 2FR4/2km，功能段却写 500m/DR8，且网址后缀为 COB；光迅 RTXM700-200 同时出现 16×100G 与 400GAUI-4 标签，需要原厂澄清。中际部分旧型号表仍只有缓存。新易盛曾在web抽取层返回异常内容，本次浏览器已正常读到官网正文与订货表；此前访问问题和漏读已纠正。Lumentum网页嵌入Features也已补读。

## 本稿能支持和暂不能支持的结论

现在可以回答若干明确产品采用的电接口、发射路线、光路和接收结构，并识别同一公司不同产品的路线差异。还不能宣布“现有全部公司、全部产品、全部环节”已列全，不能从公开产品组合计算路线市场份额，也不能据此给供应链受益排序。

关于未来路线，对话里的 400G/lane、3.2T、LPO/TRO、NPO/CPO 可以成为后续跟踪主题。本稿不把 2027/2028 的展望当成确定量产时间；以后应分别记录研发、演示、送样、认证、可供货和规模出货。


# 材料、器件、设备与模块怎么对应

材料、芯片、器件、光引擎、设备和制造服务已在页面首部独立展开，也保留在全部公司目录中。非模块产品区可按层级或公司/产品词筛选，附实现与用途、来源、日期和缺口；跨层级摘录仍保留为同一组资料。模块成品区则按公司查看具体型号、产品族、演示和历史计划。

这些类别回答不同问题：材料商供应什么，器件商实现哪个功能，设备商执行哪种工序，模块商把哪些功能组合成产品。现有资料若仅证明一家设备商提供耦合设备，不能据此连线到任意模块厂商；设备采购、试验、认证和量产使用也须区分。

联特2025年报披露了COC贴装、金丝键合、耦合、温循、老化和测试等公司通用流程，可用于建立制造步骤线索；尚不能给每个800G或1.6T SKU指定相同设备、材料或测试参数。其他公司的工艺能力同样按这一边界读取。

目标2补的是公司产品与环节实现。目标3还缺同条件性能、成本和可靠性对比；目标4还缺具体产品到工序、设备型号、材料牌号、连接参数和测试条件的证据。逐公司剩余缺口在完整目录中列出。
