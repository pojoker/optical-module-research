# 页面逻辑与可读性调整

核对与修改：2026-10-03；当前入口仍为 index.html。

旧页按资料补充过程组织：非模块摘录 → 新增公司 → 全部公司 → 覆盖数 → 模块卡片 → 对话纠错 → 阅读说明。它能检索材料，却要求读者自己从大量记录中归纳技术路线。标题问“怎样工作”，正文先给目录；同一对象重复出现，治理说明和未知字段压过已知内容。

本轮对照用户此前提供的两份浙商证券原件：《通信行业专题报告：光模块技术路线梳理》（2026-06-12）和《通信行业专题报告：光芯片产业梳理》（2026-06-30）。实际抽读目录与相关正文，视觉核对前者第6、10页和后者第6、17页；PDF页序与印刷页码一致。借鉴结构和比较方法，不将研报行业判断直接变成本稿事实。

| 可读性差距 | 研报的具体处理 | 本次调整 |
|---|---|---|
| 先给目录，答案出现太晚 | 先解释问题，再展开分类和机制 | 先用新易盛800G 2FR4走通电—光—电功能路径 |
| 术语缺乏具体位置 | 路线报告p6用模块、芯片、器件三个尺度解释结构 | 用同一具体产品解释重定时、驱动、EML、MUX、PIN和TIA的位置与连接 |
| 对比对象和维度混杂 | 路线报告p10以信号核心、发送、接收三行对齐方案 | 分别比较发光调制、光路组织、电处理；就近注明不可做性能归因的条件差异 |
| 材料、器件、模块与设备只并列 | 芯片报告p6功能分类与材料分层，p17分别画两种对象的制造流程 | 以AXT、Marvell和ficonTEC说明材料、功能芯片、组装测试分别解决什么，不虚构实际供应关系 |
| 资料与正文地位相同 | 小节围绕单一问题，图题和来源承接正文 | 连续研究正文后接统一查询区；长表、来源、20项检查和纠错按需展开 |

新版主线：具体产品如何工作 → 路线在哪些环节分叉 → 上游产品的作用 → 查公司与具体产品 → 证据和关键缺口。

查询区提供按公司、光模块型号、材料器件设备三种入口，默认每页12项，支持搜索、筛选、分页和原产品锚点跳转。正文点型号会进入对应查询页，自动显示并展开该产品。未删除全量配置或来源；数据记录数量不作为正文结论。

未知仍保留，但区分目标2的产品身份与关键实现、目标3的同条件性能经济性、目标4的生产与测试细节，避免因为设备BOM未公开就把已经能够回答的产品实现说成全部未知。

核验结果：118个R、227个C、417个PVIEW入口与原数据一致；31个公司有直达模块查询入口；唯一H1、唯一ID及内部链接检查通过；原产品事实快照和CSV指纹保持不变；JavaScript与Python语法检查通过。独立内容及源码审阅已通过。

实际视觉与浏览器交互尚未验收：工具明确拒绝当前file协议页面，本轮未通过其他浏览器或localhost绕过限制。分页、筛选和跳转已经实现并做源码复审，不将其说成浏览器实测通过。机器检查不替代领域结论审定。
