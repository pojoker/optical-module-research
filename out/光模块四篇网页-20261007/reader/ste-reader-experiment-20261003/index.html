01 / 从技术选择到制造工艺

一条技术路线，怎样决定零件和工艺？

入门页的 Coherent 800G 模块已经作出了一组选择：用 EML 发送、PIN 接收，采用并行光路和带重定时的电接口，并做成 OSFP 可插拔模块。这些选择分别影响光芯片、电路、光纤连接和封装。[1] [6]

本页按四项选择比较技术路线，再按同样的对象讲制造。每节先说明方案怎样工作，再列出改变了哪些器件，最后指向这些器件的加工或装配步骤。

  1. 发射方案：谁供光，谁调制？

    比较 EML、直接调制 VCSEL，以及激光器配合硅光或薄膜铌酸锂调制结构。器件结构决定要制造哪些材料层、波导和电极。看芯片制造 →

  2. 光路：光怎样接入光纤，多路光怎样传送？

    比较并行与波分，以及独立光学件和片上波导。选择会改变光学零件、光纤数量和对准任务。看光学件制造 →

  3. 接收与电处理：怎样探测，谁处理失真？

    比较 PIN/APD 和重定时/LPO/LRO，分别决定探测器、电路及链路验证任务。看探测器与电路制造 →

  4. 封装位置：做成面板模块，还是与主芯片共封装？

    位置改变电连接、供光、光纤引出和散热安排。看装配与测试 →

材料与集成平台会出现在具体器件的介绍中。例如，薄膜铌酸锂用于调制结构，也可以与硅光路结合；CPO 则说明器件的封装位置。四项选择需要共同满足产品的速率、波长、功率和接口要求。[47] [36]

02 / 选择发射方案

由什么器件产生光，并把数据加载到光上？

这里把供光和调制放在一起比较，因为有些器件能同时完成两件事。先看光经过哪里，再看驱动电信号接到哪里。

EML 与 VCSEL：两种不同的器件结构

EML · 同一器件内分段工作

激光段发光，调制段控制光强

光路：DFB 激光段 → EAM 调制段 → 输出
电路：供电电路接激光段；驱动信号接调制段

EML 把两个功能段做在同一个器件内。DFB 激光段持续产生光；EAM 调制段对光的吸收随电压改变，使输出光强随数据变化。[2]

需要的器件：EML、供电与驱动电路，以及输出光路。入门页的参考产品采用这类发射器。[1]

制造重点：形成两段所需材料，再加工光路与电极 →

直接调制 VCSEL · 激光器本身受控

改变驱动电流，直接改变发光强度

驱动电流变化 → VCSEL 光强变化
光从芯片表面射出 → 耦合结构 → 光纤

VCSEL 是从芯片表面出光的激光器。这里比较的直接调制方案用电流控制它的发光强度。多个 VCSEL 可以排成阵列。[34]

需要的器件：VCSEL 或阵列、驱动电路和光纤连接结构。常见实例面向短距多模光纤；Coherent 在 2023 年公布了面向 800G 短距模块的八单元阵列与配套探测器。[32] [35]

制造重点：形成激光器结构及限制电流、光场的孔径 →

激光器配合光子芯片：调制结构可以怎样做？

另一类方案由激光器提供光，再让芯片上的调制结构控制光。把波导、调制器等光学结构集成起来的芯片叫光子集成芯片（PIC）；波导就是芯片内引导光传播的通道。下面分别看硅光和薄膜铌酸锂的实例。

硅光 PIC 实例

在硅基芯片上集成调制与导光结构

激光器 → 片内波导 → 调制器 → 输出
驱动电信号接片上调制器

Cisco 的资料展示了激光器向硅光芯片供光、片内调制器加载数据的路径。同一芯片还可以集成探测器和光纤耦合结构。[28]

需要的器件：光源、硅光 PIC、驱动及接收电路、光纤连接。激光器可以位于芯片外，也可以采用集成方案；Intel 的光学 I/O 原型就是集成光源的一个实例。[37]

制造重点：在晶圆上加工波导、调制与探测结构 →

薄膜铌酸锂 · TFLN

用电场控制铌酸锂调制结构

激光器 → TFLN 调制结构 → 输出
电信号接调制器电极

TFLN 是薄膜铌酸锂的英文简称。电压会改变光波在铌酸锂中的传播快慢。以一种双臂调制器为例，它先把光分成两路，再让两路汇合。电压改变两路光波起伏的相对位置，也就是相位关系：起伏同向时相互加强，相反时相互抵消。控制这种关系，就能改变输出光强。[46]

产品实例：HyperLight 的 TFLN DR8 发射 PIC 接收一或两路激光输入，提供八通道调制，并有不同电驱动接口配置。这是发射芯片；组成模块还需要安排供光、电驱动和输出光纤连接。[45]

制造重点：在薄膜上形成波导，并对准加工调制电极 →

这两类平台也能组合。已有研究器件把铌酸锂调制区域与硅光路集成。因此，需要看实际由哪种材料承担哪项功能，再判断要制造和连接哪些结构。[47]

发射方案确定后，输出光已经携带数据。下一项选择决定光怎样接入光纤，以及多路光怎样一起传送。

03 / 选择光路

光怎样接入光纤，多路光怎样传送？

先做耦合：把器件输出的光送入下一段光路或光纤。可以用光学件对准光纤，也可以由芯片上的波导和耦合结构连接光纤。硅光实例中，光可以从芯片边缘进出，也可以通过芯片表面的光栅进出；接口位置会改变装配时怎样对准。[28] [22]

多路信号：分别走光纤，还是按波长合到一起？

并行传输

各路光分别使用纤芯

光通道 1 → 光纤 1
光通道 2 → 光纤 2
光通道 3 → 光纤 3
光通道 4 → 光纤 4

图中每路光单独传送，接收端分别接收。装配时要对准各通道，并保持正确的光纤连接关系。

波分复用 · WDM

不同波长共用一根纤芯

不同波长的光 → 合波器 MUX
→ 一根光纤 → 分波器 DEMUX → 各接收器

合波器把不同波长的光送入共同光路，接收端再按波长分开。相对图中的并行方案，所需纤芯减少，同时增加了合波和分波功能。

上图只比较一个方向的四路信号。波长可以借“颜色”来理解，但通信光通常肉眼不可见。收发双向需要分别安排光路。

Cisco 的 DR4 产品使用并行单模光纤和 MPO-12 连接；FR4 产品使用波分、双工光纤和 LC 连接。MPO、LC 是外部连接器，芯片到光纤的内部耦合还需要另行安排。两款产品距离等规格也不同，不能把性能差异全部归因于合波。[30]

选了波分后：用独立光学件合波，还是用波导合波？

三菱 2019 年 EML-TOSA

EML → 透镜 → 滤光片与反射镜 → 合波输出

滤光片对不同波长有不同的透射、反射特性。把透镜、滤光片和反射镜安排在适当位置，就能让多路光沿共同方向输出。TOSA 是发射光学子组件。[15]

制造变化：先制造光学件，再逐件定位、固定和检查光路。

POET 1.6T 发射 PIC 实例

EML 阵列 → AWG 波导合波 → 光斑匹配 → 输出

AWG 是阵列波导光栅，利用波导结构按波长合光或分光。该实例包含 EML 阵列和驱动芯片，由两个 AWG 合波；厂商披露其采用无透镜、被动装配设计。[23]

制造变化：先加工并测试波导结构，再连接光源、电路与输出端。

两例是不同规格的发射子组件，用来说明加工对象的差别。它们没有给出同等条件下的成本、节拍和良率比较。

光路把光送到接收端。下一项选择决定由什么探测器接收，以及电信号交给谁处理。

04 / 选择接收器件与电处理分工

光怎样变回电信号，谁负责恢复数据？

先选探测器，再匹配放大电路

探测器把光强变化变成电流变化，后面的跨阻放大器（TIA）再把微弱电流转换为电压并放大。仅完成这两步，还需要接收系统判断信号，才能读回数据。[33] [26]

PIN：产生电流，交给后级放大

光 → PIN → 微弱电流 → TIA

PIN 不使用雪崩倍增提供内部增益。入门页参考产品明确采用 PIN。[6] [38]

APD：先在探测器内产生增益

光 → APD 内部倍增 → 电流 → 后级放大

APD 利用内部倍增增强电流，同时需要合适的偏压与温度控制。滨松的 APD 模块实例仍配有后级放大电路。[38]

探测器也可以集成在硅光芯片内，由片内波导把光送到探测区域。因此，选择时要分别确认探测器类型、集成位置，以及它能否满足波长、速率和接收光功率要求。[28]

再决定：模块和主机怎样分担电信号处理？

电信号经过线路和器件会失真，接收端需要补偿并判断数据。这里比较三种分工；选择的是处理任务放在哪里。

带 DSP / 重定时的模块

发送和接收路径都在模块内进行数字处理，并恢复信号的时间节奏。模块需要安排数字信号处理芯片（DSP）及配套供电、散热。[3]

LPO：模块采用线性路径

模块省去 DSP / 重定时功能，由主机承担主要均衡补偿。光器件的驱动器和接收 TIA 仍然需要；Marvell 的 LPO 芯片组就是驱动器加 TIA 的实例。[3] [10]

LRO：发送重定时，接收用线性路径

两个方向采用不同分工。验证时需要分别检查发送路径与接收路径。[3]

LPO 的线性路径要求信号幅度的变化在转换与放大后保持对应关系，主机能力和连接质量也要配合。因此，改变处理分工后，装配与测试需要检查整条链路。[3] [18]

05 / 选择封装位置

光电转换器件放在设备的哪里？

发射、接收和电处理选好后，还要安排器件的物理位置。以交换机为例，光电转换可以放在面板上的可插拔模块中，也可以放进交换芯片所在的封装中。

面板可插拔模块

交换芯片 → 板上电连接 → 面板光模块 → 光纤

光模块插在设备面板的配套插槽中，OSFP 就是一种模块形态。电接口连接设备内部电路，光接口连接外部光纤。带 DSP 的模块和 LPO 都可以采用可插拔形式。[7] [3]

CPO：光引擎与交换芯片共封装

同一封装：交换芯片 → 短电连接 → 光引擎
光引擎 → 光纤 → 面板光连接

光引擎是完成光电转换的一组器件。Cisco 的 OFC 2023 演示把硅光光引擎与交换芯片装在共同的封装基板上，基板支撑并连接这些器件。短电连接减少了信号在电路板上经过的距离。[36]

这项选择主要改变封装与装配。CPO 需要在主芯片周围安排供电、散热和光纤引出。激光器的位置还可以另行选择：上述 Cisco 演示把激光器放在交换芯片封装外，通过光连接供光。这里说明一个演示实例的布局。[36]

把四项选择连成一套方案

入门页的产品可以读成：EML 发射、PIN 接收 → 并行光路 → 带重定时电接口 → OSFP 面板模块。Cisco 的演示则说明硅光平台可以与 CPO 封装共同使用。已有实例支持这些具体组合，其他组合仍要核对波长、速率、功率和电光接口。[1] [6] [36]

现在已知道每项选择会改变什么。下面按器件制造、零件制造和装配三个环节，把这些变化落实到工艺与设备。

06 / 把路线选择变成制造和装配动作

这些器件怎样做出来，再怎样连成产品？

先把材料加工成芯片和零件，再把这些实物固定、连接和测试。前文选择的发射方案，决定需要制造哪些光芯片；光路、接收与电处理、封装位置，则继续决定要连接哪些接口、怎样装配和验证。

阶段一 · 制造芯片和零件

在材料上做出所需结构

晶圆是供批量加工芯片的圆片。芯片通常先在晶圆上成批加工，再分成单颗裸片。外延或沉积形成材料层，光刻定义图形，刻蚀去除指定位置的材料，金属化形成电连接。各类芯片使用的材料、层结构和工序不同。[4] [8]

阶段二 · 装配并连接

把做好的实物接到一起

固晶设备固定裸片；引线键合或倒装设备建立电连接；光学装配设备把芯片、光学件和光纤放到所需位置。连接完成后，再检查光、电和整条链路的性能。具体采用哪些步骤，由器件接口和封装设计决定。[19] [22] [27]

以下区分两种依据：制造实例说明来源实际披露的工序；装配表中标为“按接口推导”的内容，解释设备需要完成的任务。它们都不能直接当作入门页参考模块的实际产线清单。

EML：在同一器件内做出激光段和调制段

选择 EML，就要制造相连的发光区域和调制区域，并做出让光通过的路径以及各自的电接触。NTT 在 2010 年公开的 EML 工艺提供了一个具体例子。这里的外延是按设计生长晶体层，刻蚀是去除选定位置的材料。[2] [4]

材料要成为哪种结构？怎样加工？设备类别与动作
激光段、调制段所需的材料层生长所需晶体层；按器件结构，在局部去除材料，再生长所需层。MOVPE 外延设备控制晶体生长；刻蚀设备去除指定区域。[4]
导光路径和电接触形成波导，处理表面，制作电接触。干法、湿法刻蚀设备加工相关结构；表面处理和金属化设备处理表面及电连接位置。[4]
可独立装配的芯片与光学端面减薄、解理，给端面镀膜。减薄设备控制厚度；解理设备分出器件；镀膜设备处理光学端面。[4]

NTT 比较的两种结构所需工序不同：一种省去了调制区量子阱的再生长；另一种允许更独立地设计两个区域。这个实例说明，选定 EML 后仍需选定器件结构，才能确定工序。它是 2010 年的历史实例。[4]

VCSEL：以氧化孔径为例，先暴露目标层，再形成孔径

直接调制 VCSEL 需要制造发光器件本身。现有 Oxford Instruments 资料只披露了氧化孔径路线的一个关键环节：在芯片上刻出局部台面，让富铝层露出，再通过氧化形成孔径。[20]

这里的氧化孔径是中央保留的未氧化半导体区域，其中仍有材料。外围氧化后形成绝缘区，使电流集中通过中央区域；氧化区与未氧化区的光学性质不同，也帮助限制光在横向的分布。[48]

要形成的局部结构怎样加工？设备类别与动作
露出富铝层的台面刻蚀 p-mesa，即器件的局部台面，控制深度直到目标层露出。带终点控制的等离子体干法刻蚀设备：控制何时停止去除材料。[20]
氧化孔径使富铝层的外围发生氧化，保留中央未氧化区域作为孔径。高温氧化设备：控制氧化形成的区域。[20] [48]

孔径也有其他实现方向。Coherent 在 2024 年披露了用光刻定义孔径结构的研发信息。氧化孔径和光刻孔径不能合并成一套通用步骤；上述资料也没有给出完整的 VCSEL 晶圆工艺。[21]

硅光：在晶圆上做出波导、器件区域和电连接

选择“激光器＋硅光调制器”时，需要制造承载调制和导光结构的光子集成芯片（PIC），并安排供光。AIM Photonics 的工艺设计套件列出了波导、注入层、锗探测器和金属布线等可用结构。下面按这些结构说明加工任务；表中不是 AIM 的完整设备清单。[5] [28]

材料要成为哪种结构？怎样加工？设备类别与动作
片内波导和光学图形先定义图形，再把图形转移到材料中。光刻设备定义位置与形状；刻蚀设备去除选定材料。[5] [8]
器件所需的材料层与局部电学区域按平台要求生长或沉积材料，并在指定区域掺杂，改变局部电学性质。沉积、生长及掺杂相关设备分别完成材料与电学区域加工；不同层采用什么方法，需按平台确认。[5] [8]
可连接外部电路的金属结构加工金属层，形成电连接。金属层加工设备形成导电路径与接触位置；芯片完成后，才进入与电子电路和光纤的装配。[5]

光源还要单独核对。Cisco 资料说明激光器向硅光芯片供光的路径；Intel 的 2024 年原型采用片上集成激光器。两者的集成方式不同，不能从“硅光”一词确定激光器是否外置、用了多少颗裸片。[28] [37]

TFLN：把薄膜铌酸锂加工成调制光路

这条方案需要先把薄膜铌酸锂做成导光和调制结构，再连接光源与电驱动。Wang 等人在 2018 年的研究从商用的绝缘体上铌酸锂晶圆开始，制作前文介绍的双臂调制结构：光路在片内分支后重新汇合，电极用于施加调制电信号。[46]

材料要成为哪种结构？2018 年研究中的加工动作设备类别与动作
薄膜中的波导与分支、汇合光路用电子束曝光定义图形，再用氩离子刻蚀去除指定材料。电子束曝光设备定义细小图形；刻蚀设备把图形加工到薄膜中。[46]
与光路对应的金电极再次曝光并对准电极位置，通过金属加工及剥离形成电极图形。剥离会去掉不需要保留的金属。涂胶、曝光及金属电极加工设备完成电极制作。[46]
二氧化硅包覆层在器件上沉积包覆层。等离子体增强化学气相沉积（PECVD）设备形成二氧化硅薄膜。[46]
用于光学连接的芯片端面切割芯片并抛光端面。切割与抛光设备处理器件及其光学端面。[46]

这些步骤说明了一个研究器件怎样从商用晶圆变成调制芯片。HyperLight 的发射 PIC 则是另一份产品资料，列出了单路或双路激光输入、八个调制通道及不同电驱动接口，未披露上述制造配方。[45] [46]

探测器：做出吸收光、收集电荷和接出电流的区域

接收端的探测器有自己的制造过程。Ho 等人在 1995 年公开的 InGaAs/InP PIN 实例，展示了从材料层到电接触的几个步骤。若探测器集成在硅光 PIC 内，则还要按该平台的器件结构和工艺核对。[9] [5]

1995 年 PIN 实例中的结构制造动作设备类别与动作
所需材料层与局部电学区域MOVPE 外延；在掩膜限定的位置进行 Zn 扩散。外延设备生长材料层；扩散设备配合掩膜改变局部电学区域。[9]
接触窗口、电接触和表面膜层刻蚀、金属化，并形成钝化和增透层。刻蚀设备开出窗口；金属化设备制作电接触；镀膜设备形成表面膜层。[9]

该 PIN 样品的工艺不能直接套到现代高速 PIN 或 APD 上。现有 APD 资料确认了内部增益、偏压与温度控制要求，但没有给出可用的制造流程。[38]

电子芯片：先加工电路，再选择互连方式

驱动器（Driver）、跨阻放大器（TIA）和数字信号处理芯片（DSP）各有自己的电路设计。通用硅芯片制造可以帮助理解设备的分工，但具体型号采用的材料、工艺节点和完整步骤仍需各自核对。[8]

要形成的结构制造动作与设备类别与后续装配的关系
电路层和局部电学区域沉积设备形成薄膜；涂胶、曝光设备定义图形；刻蚀设备去除材料；离子注入等设备改变局部电学性质。[8]这些工序加工芯片本身。800G、1.6T 是模块速率，不能用来确定芯片制程。
可装配的芯片及电连接完成晶圆加工后分出芯片；按芯片接口和载体，使用固晶、引线键合或倒装设备。[8] [27]固晶把芯片固定到承载结构；引线键合用细金属线连接电接点；倒装让芯片接点朝向载体完成连接。具体方式由封装决定。

光纤阵列、光学件和载体：先加工几何结构，再检验

光路能否对准，也取决于芯片以外的零件。光纤阵列（FAU）把多根光纤固定在规定位置；透镜和合波结构引导光；电路板、壳体与散热结构承载并连接这些器件。

零件制造动作与设备类别做好后检查什么？
FAU 光纤阵列研磨设备加工基座；精密切割设备加工 V 槽；排纤定位设备放入光纤；UV 固化设备完成相应粘接。Corning 实例测量纤芯间距。几何测量之后，还需检查 FAU 与芯片连接后的耦合。[12]
透镜玻璃模压设备使玻璃按模具成形；另一类方法用精密研磨和抛光设备加工曲面。用轮廓或干涉测量检查形状。这些是非球面透镜的制造方法示例。[24]
合波结构空间光学方案取放并装配透镜、滤光片和反射镜；波导方案需要加工片内导光结构，再连接光源及输出接口。检查各波长是否进入预定输出路径。现有实例未给出完整的镀膜或波导加工配方。[15] [23]
裸电路板（PCB）成像和蚀刻设备制作线路；压合设备叠合各层；钻孔和电镀设备制作层间连接。用自动光学检查（AOI）和电测检查裸板，之后再装配器件。这里采用普通多层板的制造实例。[11]
壳体与散热接触面按尺寸、表面几何和热设计要求确定加工及装配任务；现有资料不足以指定加工设备。OSFP Rev 5.0 规定了部分尺寸与散热要求，但未规定必须使用数控加工或压铸。[7]

回到发射方案：做好的器件怎样装配？

装配时，要沿实际接口安排器件：电信号接到哪里，光从哪里出来，再进入哪里。主动对准是一边测量传入的光功率，一边调整部件的位置；被动对准则依靠定位结构和装配精度完成定位。两者都需要合适的器件与封装设计。下表除明确写为厂商披露的项目外，均为按接口推导的设备任务。[19] [22]

发射方案与连接对象装配设备需要做什么？连接后验证什么？
EML
驱动电路 → EML → 光学件或光纤		采用裸片时，用固晶或贴装设备固定芯片，并按接口建立电连接。精密取放与定位设备把输出光路接到光纤；若设计采用主动对准，再由运动台配合测光仪器调整位置，最后固定部件。[2] [19] [27]检查各发射通道的光输出、耦合和固定后的稳定性。入门页 DR8+ 资料只公开并行接口，没有披露其透镜、载体、对准或键合方式。[6]
直接调制 VCSEL
驱动器 → VCSEL 阵列 → 多模光纤通道		贴装设备固定阵列；阵列对准设备安排发光单元与光纤的位置及间距；测光仪器检查通道耦合，再固定光路。接收侧还需安排配套探测器阵列。[34] [35] [42]检查每个单元是否连到正确纤芯，以及各通道的输出。表面出光仍需要对准；ficonTEC 的阵列耦合能力资料不能证明某款通信产品使用其设备。
激光器＋硅光 PIC
供光接口、调制器电接口、PIC 与光纤接口		贴装和互连设备连接 PIC 与电子芯片；片外供光时，还要连接光源与 PIC。精密定位设备连接光纤或 FAU。边缘耦合与表面光栅耦合的接口方向不同，夹持方向和装配空间也需配合。[12] [22] [27] [28]检查供光、调制后的输出以及外部光纤连接。采用片上激光器的实例不再外接同样的供光路径；具体用主动还是被动对准，仍按封装确认。[37] [41]
激光器＋TFLN 调制 PIC
光源 → 调制芯片 → 输出光纤；电驱动接调制芯片		按产品披露的接口推导，需要固定芯片、建立电连接，并连接输入光源和输出光纤。对应贴装、电互连、光学定位及测光任务；具体设备组合和对准方式依实际封装确认。[45]核对激光器输入路数和电驱动接口，检查供光、调制输出与光纤耦合。HyperLight 未公开具体装配工艺，不能由接口直接确认键合方式。

接收端也要完成对应的光、电连接：把光送到探测器，并把探测器接到 TIA。若探测器在 PIC 内，装配对象随之改变；若采用 APD，还需安排偏压与温度控制电路。完成这些连接后，再进行接收性能和误码测试。[28] [38] [18]

光路、电处理和封装位置，还会改变哪些装配任务？

发射器件相同，后续装配也可能不同。例如，同样使用 EML，逐路连接光纤、用空间光学件合波、用波导结构合波，就需要安排不同的零件和接口。

前文的路线选择增加或改变的装配任务对应设备与验证重点
并行光路各路光分别连接对应纤芯；阵列方案还要保持通道间距和连接顺序。精密定位与测光设备逐通道检查输出、耦合和对应关系。FAU 的纤芯间距测量不能代替耦合检查。[6] [12]
波分＋空间光学件
三菱 EML-TOSA 实例		在 EML 后装配透镜、滤光片等部件，让不同波长的光进入共同输出路径。精密取放、角度与位置调整设备安排光学件；光学测量检查各波长的耦合、通带和串扰，固定后再验证。资料未指定完整设备清单，也不能由示意图确定胶粘或焊接。[15] [22]
波分＋波导合波
POET 混合集成 EML 实例		厂商披露四组 2×200G EML 阵列倒装到光学中介层，配合八路驱动器、两个阵列波导光栅（AWG）和光斑尺寸转换结构。该实例明确采用倒装及被动晶圆级装配；厂商称其设计无需透镜和主动对准，因此设备任务以倒装贴装或键合为主。仍需检验所装器件与输出接口的光学性能。[23]
VCSEL＋短波波分（SWDM）四种波长的 VCSEL 经合波器汇入发送多模光纤；接收端经分波器连接各 PIN。增加合波、分波组件定位与各波长通道验证。该白皮书未披露组件内部结构，因此不能直接套用上面的滤光片装配流程。[39]
接收与电处理选 LPO装配所选光器件、驱动器和 TIA，并配合主机提供线性链路所需的电连接。贴装与互连方式仍按器件接口决定。电测试和误码测试需覆盖主机与模块连接后的链路，检查主机通道和线性性能。[3] [10] [18]
封装位置选 CPO
Cisco 2023 年演示		光引擎移到主芯片附近，安排封装内短电连接、供电、散热及光纤引出。该演示还需连接远置、可更换的光源。按所用封装安排芯片贴装、电互连和光纤定位设备，并检查这些接口。演示说明了位置与系统安排，没有公开完整键合工艺及设备清单。[36]

资料能说明什么，哪些制造信息仍是 UNKNOWN？

具体产品：Driver、TIA、DSP 的材料、制程与工艺需逐型号确认；参考产品的壳体加工设备、内部导热材料仍为 UNKNOWN。普通多层 PCB 的制造实例不能证明某条产线能制造某款高速板；非球面透镜示例也不能推广到所有模块微透镜。

装配与验证：多数设备类别按公开结构和接口推导，不表示参考产品使用了该设备。POET 厂商披露不能证明量产良率，也不表示全部外部接口无需对准；Intel 光学 I/O 和 Cisco CPO 资料各有原型或演示边界。实际装配顺序、固定方式、产测流程、测试时长和设备型号，仍需产品与产线资料。
