# 光模块网页 workflow · 7a8053a

此包对应GitHub PR #2的提交7a8053a，是网页生成流程与当前内容的可运行快照。

## 直接阅读

在此目录运行 `python3 -m http.server 8769 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8769/out/光模块知识体系/index.html 。基础页是01-foundation.html；决策卷宗是07-decision-dossier.html。

## 重新生成

需要Python 3.10或更新版本。先执行 `python3 -m pip install -r requirements.txt`，再执行 `python3 tools/site/build_optical_module_site.py`。不要使用脚本的--refresh-sections选项，该选项用于旧版迁移，不是日常构建。

## 内容怎样变成网页

1. docs/source-conversations保存三段原始问答；它们是研究起点，不是自动可信的事实。
2. docs/reviews保存零件工艺和Driver到光纤的研究解释与来源。
3. site/optical-module/sections保存按读者问题编写的正文；术语解释与交互随基础页片段保存。
4. pages.yaml规定页面顺序和片段组合，templates与assets提供布局和图示。
5. tools/site/build_optical_module_site.py组合生成out/光模块知识体系；不写入正式事实账本。
6. site/optical-qa是保留的独立问答页，不由上述构建器生成。

当前基础页有24个主体问题、105个术语问答和10张图。8张实物或厂商图沿用远端URL，需要联网；另2张SVG随包提供。来源链接也需要联网。

## 范围

此包可重建网页，不是自动从GPT问答生成研究结论的系统；研究与解释编辑仍需人工或助手核对。知识账本随包只用于构建器读取及不变性检查，不包含年报原始大语料、日更采集器、登录凭据或飞书配置。包内历史控制文档用于记录，执行新任务以使用者当次授权为准。
