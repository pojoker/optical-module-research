# Driver → EML → 光耦合 → 光纤：把同一对象的接口连起来

**本轮得到的是一条能在同一发射PIC上追踪的功能路径，尚不是可复现的生产配方。**原参考Coherent FTCE4527E1PCA的公开产品页与规格书提供EML、PIN、外部接口等信息，但本轮未取得它内部Driver到EML、EML到光纤的装配证据。[1][6] 因此不会用其他公司的器件资料填进它的BOM。

深读对象改为一个明确命名的子组件：**POET于2025-12-08介绍的Hybrid-Integrated 1.6T 2×FR4 Transmitter PIC**。这里固定的是该次披露的发射PIC设计，不是完整收发模块，也没有把它认定为已验证量产的具体订货型号。[23]

## 1. 先看整条路径：哪些连接有证据，哪些只是功能重建？

同一篇产品说明列出四个2×200G EML阵列、八个Driver、两个AWG复用器及面向单模光纤的SSC光斑尺寸转换器，并披露EML阵列倒装在Optical Interposer上。[23]

```text
电信号：Driver ──电互连──► EML的调制端
                             │
光信号：                EML输出光
                             ▼
                    芯片上的光路与AWG复用
                             ▼
                        SSC输出接口
                             ▼
                          单模光纤
```

**图的身份：**根据同一产品已披露的功能块重建的阅读示意。各块存在有产品说明支持；具体端口对应、波导走向、SSC位置和连接细节尚无足够图纸确认。图中箭头不能当成已验证的版图或装配顺序。[23]

与此前相比，进展是“这些块属于同一个披露对象”已经成立；“每条边的物理实现已经讲清”仍未成立。

## 2. Driver到EML：知道要连接，还缺什么才能说明怎样连接？

该产品说明宣称采用无引线键合的互连；平台介绍提到RF重布线层和有源器件倒装。这支持沿倒装及载体布线方向追查，但平台能力不能直接指定该产品每一段连接的实际层数、凸点结构或TSV实现。[23]

下一步需要把这条边拆成三个可核查对象：

| 待确认对象 | 要取得的产品级证据 | 为什么它能推进解释 |
|---|---|---|
| Driver输出端 | 芯片型号、输出接口和驱动摆幅、偏置定义 | 才能说明它具体给EML什么电信号 |
| 两颗芯片之间 | 本产品连接剖面、凸点与布线示意、回流路径 | 才能从“靠得近”进入真实电流路径 |
| EML电输入端 | 电极定义、负载或等效电路、接口测试条件 | 才能判断驱动与负载是否匹配 |

这三项本轮均未取得完整披露。不能指定Driver供应商、把任意200G Driver规格贴进来，或替厂商算出未经证实的阻抗和功耗。

**工艺追问：**倒装前检测哪一个界面？倒装后是否检查连接电阻、空洞和高速传输？这是一组待验证问题，不是已知产线工序。

## 3. EML到光耦合：不能把一个箭头直接叫“对准设备”

POET称该发射PIC采用无透镜、无主动对准的被动装配。[23] 这是厂商对该对象的声明。它没有使EML光输出端到芯片光路之间的物理接口自动透明。

这条边值得继续拆成两件事：

- **接口几何：**出光面与接收光路的相对位置、间隙、高度和角度由什么结构决定？需要产品剖面和公差定义。
- **装配与保持：**怎样定位、固定，固定后怎样确认光学性能？需要针对这个接口的制造说明和测试记录。

这些是本轮的研究问题。没有证据时，不把“被动”翻译成某种特定V槽、焊料自对准或视觉定位方案，也不套用另一家设备商的主动对准流程。

这里最需要的不是再找一家“能做精密贴装”的公司，而是一张能标出**EML出光口与芯片光路入口**的本产品截面图。

## 4. 光路到光纤：SSC不是完整的光纤装配方案

产品说明给出SSC与单模光纤的模式匹配，并宣称耦合损耗小于0.5 dB。[23] 该数字应保留为厂商披露；本轮没有取得完整测量条件，不能把它当成EML到光纤全路径损耗或量产良率。

需要继续核实：

| 问题 | 本轮状态 | 最有用的后续资料 |
|---|---|---|
| SSC与光纤在哪里相接？ | 具体截面、间隙和端面条件未知 | 该产品光接口图 |
| 使用独立光纤还是FAU？ | 未取得足以判定的产品级说明 | 出纤装配图和物料说明 |
| 光纤怎样固定？ | 胶、焊接、机械夹持等均不能先指定 | 固定工艺说明 |
| 小于0.5 dB在哪里测？ | 输入/输出参考面、波长与温度条件不完整 | 测试方法及原始曲线 |
| 装好后能否保持位置和性能？ | 未取得可靠性与批次分布证据 | 热循环、老化及批次测试 |

“耦合结构存在”“一次测得低损耗”“稳定制造出合格组件”应分别寻找证据，不能相互替代。

## 5. 现在能不能列出这个产品的制造流程？

**能列研究顺序，不能列已证实的生产先后顺序。**本轮适合按下面顺序继续取证：

1. 找到电连接剖面，解释Driver输出怎样到达EML电极。
2. 找到光连接剖面，解释EML光场怎样进入芯片光路。
3. 找到出纤装配图，解释SSC怎样与光纤定位和固定。
4. 找到各接口测试边界，把“哪一处做坏了”与“哪一个测试会发现”对应起来。

这也给设备研究设下了具体入口：**先确定实际制造动作和验收指标，再判断需要哪类设备。**本轮不会列出某厂商的固晶机、对准机、点胶机，冒充该PIC已经采用的设备清单。

## 6. 下一份资料应该找什么？本轮检索到了哪里？

最优先的是同题ECOC 2025论文的完整正文及结构图，其次是该发射PIC的应用说明或封装图。本轮检索定位到论文题名与DOI线索，但出版入口读取失败，未取得全文。因此正文不引用论文中未读到的工艺，也不把公司文章标作已核读会议论文。

如果下一轮仍只能取得公司平台介绍，就应把接口继续留空。只有同产品资料能填入上面的三条边；通用论文可另用于解释物理原理，不能用来证明该产品采用了相应实现。

**本轮最值得先追的一个断点：Driver输出焊盘 → 本产品的倒装/布线结构 → EML调制电极。**判断是否推进的标准，是能否画出有来源的连接剖面，并说明驱动条件与测试边界；不是新增了多少技术名词。
