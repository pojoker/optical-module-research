光模块本质上是在做一件事：**电信号 ↔ 光信号的转换，并把光可靠地送进/接出光纤。**

所以从功能上拆，一个典型高速光模块可以看成下面几大部分：

```text
光模块
├── 1. 电芯片
│   ├── DSP
│   ├── Driver
│   └── TIA
│
├── 2. 光芯片 / 光器件
│   ├── Laser
│   │   ├── EML
│   │   ├── DFB
│   │   └── CW Laser
│   ├── Modulator
│   ├── Photodiode / PD
│   ├── Waveguide
│   └── Mux / Demux
│
├── 3. 光耦合
│   ├── Lens
│   ├── Fiber Array
│   ├── FAU
│   └── Grating / Edge Coupler
│
├── 4. 封装与电连接
│   ├── PCB
│   ├── Substrate
│   ├── Wire Bond / Flip Chip
│   └── Connector
│
├── 5. 散热与结构件
│   ├── Housing
│   ├── Heat Sink
│   └── TIM
│
└── 6. 光纤接口
    ├── LC
    ├── MPO
    └── SN / MDC 等
```

但如果你是为了**研究产业链和投资机会**，我建议不要只背这个 BOM，而是理解信号怎么走。

比如一个典型的发射端：

**交换芯片电信号 → DSP → Driver → 激光器/调制器 → 波导 → Mux → 光耦合 → 光纤**

接收端正好反过来：

**光纤 → 光耦合 → Demux → PD → TIA → DSP → 交换芯片**

这里最关键的是几个东西：

**DSP**负责高速数字信号处理，比如均衡、纠错、SerDes 相关处理。高速率时代功耗很大，所以才会出现 LPO、LRO、CPO 这些路线。

**Driver / TIA**是模拟前端。Driver 驱动发射端的调制器或激光器，TIA 把接收端 PD 很小的电流信号放大。

**Laser**负责产生光。EML 路线里激光器和调制器通常集成在 InP 芯片上；硅光路线经常使用外部 CW laser，然后由硅光芯片上的调制器来调制。

**Modulator**负责把数据“写”到光上。这个是你之前容易把 EML 和硅光混在一起的地方：EML 本身已经包含激光产生+调制，而硅光通常把调制器、波导、Mux 等集成在 SiPh 芯片里。

**PD**负责光→电转换，常见材料包括 InGaAs。

**Mux/Demux**是多波长复用，比如把 4 路不同 wavelength 合成一根光纤。

**光耦合**就是把芯片里的光送进光纤，或者反过来。这里涉及 lens、FAU、fiber array、edge coupler、grating coupler，也是现在精密耦合设备价值量不断提高的原因之一。

你还可以进一步把光模块简化成投资研究最有用的 **5 层**：

> **电芯片 → 光芯片 → 光路 → 封装 → 光纤**

然后每一层再问一句：

> **800G → 1.6T → 3.2T 后，这一层发生了什么变化？**

这样你就会自然得到：

**DSP功耗↑ → electrical reach缩短 → Driver/TIA位置变化 → SiPh/CPO价值提升 → 光耦合精度提高 → advanced packaging增加 → 散热价值量提高。**

这比单纯记“光模块由哪些零件组成”更适合你后面分析 **中际旭创、新易盛、Lumentum、Coherent、POET、光耦合设备厂商**。

## 不要把“零部件”和“技术路线”混在一起

这是大多数光模块产业链文章最容易让读者混乱的地方。

比如：

- DSP：部件
- EML：光源/调制方案
- SiPh：光子集成平台
- LPO：电架构
- CPO：封装架构

它们根本不是一个维度。

所以你应该在第一章明确告诉读者：

> **一个光模块可以同时拥有多个技术属性。**

> 一个模块可能是：
>
> **Pluggable + DSP + SiPh + CW Laser**

另一种可能是：

> **Pluggable + DSP + EML**

未来也可能是：

> **CPO + SiPh + CW Laser**

这样读者以后再看到“EML vs SiPh”“LPO vs CPO”，就不会把完全不同维度的东西放在一起比较。

# 三、第二章：每一个部件到底是怎么做出来的？

这一章就是你构想里的第二部分。

而且这是整套研究真正开始产生**产业价值**的地方。

不要只是：

> EML → 光刻机

这种简单对应。

而应该统一采用：

> **材料 → 晶圆 → 芯片 → 封装 → 测试**

这个制造框架。

| Lens → Fiber/FAU | 光进入光纤 | Fiber Alignment / Attach | **光纤耦合设备** |
| Fiber → PD | 把接收光送到PD | Optical Alignment | **Active Alignment / Fiber Attach设备** |
| PD → 基板 | 固定PD | Die Attach | **Die Bonder** |
| PD → TIA | 微弱高速信号互连 | Wire Bond / Flip Chip | **Wire Bonder / Flip Chip Bonder** |
| TIA → DSP | 高速电互连 | PCB/封装互连 | **SMT / Bonding设备** |
| PCB → Housing | 模组装配 | Mechanical Assembly | **自动组装设备** |
| Chips → Heat Sink | 导热 | TIM dispensing / attach | **点胶设备 / 压合设备** |
| 完整模块 | 验证性能 | Optical/Electrical Test | **BER Tester、OSA、Power Meter、ATE** |
| 完整模块 | 老化筛选 | Burn-in | **Burn-in Chamber / Oven** |

这张表就是你后面研究**设备价值量变化**的入口。

# 1. DSP、MCU、PMIC 怎么装到 PCB 上？

这一部分最接近普通电子产品制造。

典型流程：

```text
Bare PCB
↓
Solder Paste Printing
↓
Component Placement
↓
DSP / MCU / PMIC / Passive Components
↓
Reflow
↓
AOI
↓
Electrical Test
```

主要设备：

**锡膏印刷机 → SMT贴片机 → 回流焊炉 → AOI → 测试设备**

DSP 往往是封装好的芯片，所以这一层不是光模块厂自己制造 DSP，而是：

> 买入 DSP package → 安装到 PCB。

# 2. Driver / TIA / EML / PD 怎么固定？

这里开始进入**半导体封装**。

最基础动作叫：

## Die Attach

意思就是：

> 把一颗裸 Die 精确地放在基板 / carrier / substrate 上。

比如：

```text
Carrier
  │
  ├── EML Die
  ├── Driver Die
  ├── PD Die
  └── TIA Die
```

对应核心设备：

# **Die Bonder**

这类设备的重要性非常高。

ASMPT 的光子器件设备明确覆盖 PD、TIA、EIC 等多芯片精密贴装，并将下一代 1.6T optical transceiver 作为应用方向；其超高精度设备可以做到微米甚至亚微米级 placement accuracy。citeturn206777search24turn206777search25

---

# 3. Driver 怎么和 EML 连起来？

这是非常关键的一根“箭头”。

```text
Driver
  │
 electrical signal
  ▼
EML
```

最传统的办法之一是：

## Wire Bond

例如：

```text
Driver Die
   ╲
    ╲ Gold Wire
     ╲
      EML Die
```

对应设备：

# **Wire Bonder**

但速率越来越高以后，一个核心问题就是：

> Wire越长 → parasitic inductance/capacitance越大 → 高频信号越差。

所以产业趋势之一就是：

> **Driver越来越靠近EML。**

甚至：

> Wire Bond → Flip Chip / 更紧密封装。

这就是后面讲 200G/lane、1.6T 时非常重要的一条线。

---

# 4. EML 怎么和 Fiber 接起来？

这恰恰是**光模块区别于普通电子产品的核心制造步骤之一**。

EML 出来的光，需要进入光纤：

```text
EML
 ↓
Lens
 ↓
FAU
 ↓
Fiber
```

问题在于：

> 两个东西不能“差不多对上”。

位置稍微偏一点，耦合效率就会明显下降。

所以生产的时候会：

```text
EML发光
↓
机械平台移动Fiber / Lens
↓
实时测量输出光功率
↓
X/Y/Z移动
↓
调整Pitch/Yaw
↓
寻找最大光功率位置
↓
固定
```

这就是：

# **Active Alignment**

典型设备包含：

- 高精度运动平台
- Machine Vision
- Optical Power Meter
- Alignment algorithm
- Dispensing
- UV curing

ASMPT 就把主动/高精度对准与 photonics assembly 作为重要设备能力，其光子 Die Bonding 设备已做到亚微米级 placement。citeturn206777search9turn206777search34

所以以后你看到：

> **光耦合设备**

不要把它理解成简单“把光纤粘上去”。

它本质上是：

> **测光 → 精密移动 → 找最佳位置 → 固化。**

---

# 5. Fiber → PD 是怎么连的？

接收端也是一样：

```text
Fiber
 ↓
Lens / optical structure
 ↓
PD
```

PD 把光变成电。

Coherent 当前高速 InP PD 就是面向 800G/1.6T、200Gb/s PAM4 optical lane 应用。citeturn206777search1

这一层同样涉及：

- Lens placement
- Fiber alignment
- PD alignment

设备依然是：

> **Active Alignment + Die Bonder + Fiber Attach**

---

# 6. PD → TIA 为什么特别重要？

这是另一个非常值得研究的箭头：

```text
PD
 ↓
very weak electrical signal
 ↓
TIA
```

PD 产生的是很小的 photocurrent。

所以：

> **PD和TIA必须尽量靠近。**

否则：

- parasitic capacitance ↑
- noise ↑
- bandwidth ↓

因此高端光模块经常会看到：

```text
PD + TIA
```

做得非常紧凑。

这里需要：

### Die Bonder

把 PD/TIA 精准摆放。

+

### Wire Bonder / Flip Chip Bonder

完成高速电连接。

ASMPT 的 photonics 平台明确把 **PD、TIA、EIC** 作为多芯片 bonding 对象。citeturn206777search24

↓
Calibration
↓
Optical Test
↓
Electrical Test
↓
BER Test
↓
Thermal Test
↓
Burn-in

### 光

- Optical Power
- Wavelength
- Eye Diagram

- Receiver sensitivity

### 电

- BER
- Signal integrity
- Power consumption

### 可靠性

对应：

- **Oscilloscope**
- **Optical Spectrum Analyzer**
- **Optical Power Meter**

- **Temperature Chamber**

## 如果压缩成设备产业链，其实就是 7 类

**① SMT设备**  
把封装芯片和电子元件装到 PCB。

**② Die Bonder**  
把 EML、PD、Driver、TIA 等裸芯片精准放好。

**③ Wire Bonder / Flip Chip Bonder**  
实现芯片间高速电连接。

**④ Active Alignment设备**  
寻找最佳光路位置。

**⑤ Fiber Attach / Coupling设备**  
把光芯片真正连接到光纤。

**⑥ Assembly / Dispensing / Thermal设备**  
固定、点胶、散热、装壳。

**⑦ Optical + Electrical Test设备**  
保证最后这只模块真能跑 800G。

这实际上就是你整份研究里一个非常重要的分界点：**前面研究“零件是谁做的”，从这里开始研究“谁把零件连接起来”。**

而到了 **800G → 1.6T → 3.2T**，最值得追踪的往往不是“是不是又多了一颗芯片”，而是：

> **哪些箭头变得更难了？**

因为箭头越难，通常意味着 **贴装精度、互连精度、光耦合、测试、封装设备的价值量发生变化**。

## 1. EML：最值得你详细拆

Lumentum明确说明其 EML 是在 **InP wafer foundry** 中制造，结构是 DFB laser 与 EAM 单片集成。citeturn478946search3turn478946search1

可以把制造流程简化成：

```text
InP substrate
↓
外延生长
↓
光刻
↓
刻蚀
↓
形成 DFB grating / waveguide / EAM
↓
介质层沉积
↓
金属电极
↓
钝化
↓
晶圆测试
↓
Cleaving / Dicing
↓
Facet coating
↓
Chip test
```

### A. 外延

要在 InP 衬底上长出：

- InGaAsP / InAlGaAs active layer
- quantum well
- cladding layer

核心设备：

> **MOCVD**

也可能存在 MBE，但大规模 III-V 光器件生产里 MOCVD 极其重要。

Coherent也明确把 III-V epitaxial wafer 用于 laser、detector 等光电器件。citeturn478946search5turn478946search26

所以第一层产业机会就是：

**InP substrate → MOCVD → Epitaxial wafer**

---

### B. 光刻

把：

- DFB grating
- waveguide
- mesa
- electrode pattern

做出来。

设备：

> **Lithography**

但这里不要简单理解成“必须 EUV”。

EML 的关键更多是：

- 光刻精度
- grating pattern
- overlay
- 工艺一致性

---

### C. 刻蚀

例如：

> 把 waveguide、mesa、grating 等结构真正刻进 III-V 材料。

设备：

> **ICP / RIE Dry Etcher**

这是 EML 和 SiPh 都非常重要的一类设备。

---

### D. 薄膜和金属化

需要：

- dielectric
- passivation
- metal electrode
- contact

设备：

> PECVD  
> PVD / sputter  
> evaporation

---

### E. 劈裂 / 切割

Laser 和普通 IC 又不太一样。

激光器的：

> **facet**

本身就是光学界面。

因此 InP laser 经常涉及：

**wafer → bar → chip**

设备可能包括：

> Cleaver  
> Dicing equipment

---

### F. Facet coating

激光器的前后端面需要不同反射率。

因此会做：

- AR coating
- HR coating

设备：

> **Optical coating equipment**

这个设备链在普通逻辑 IC 中基本不存在。

---

### G. 测试

EML不是通电亮了就行。

要测：

- LIV
- wavelength
- optical power
- spectrum
- extinction ratio
- modulation bandwidth

所以：

> **LIV tester / OSA / high-speed optical test**

也是非常重要的一层。

每两个功能块之间都问一句：

> “A的输出能直接成为B的输入吗？”

不能，就说明中间漏了部件。

这个办法比找一张网上的 BOM 图可靠得多。

---

### 第五步：再从“电子/光学功能”扩展到完整产品

到这里得到的只是**信号链**，还不是完整光模块。

所以我会再问四个问题：

**这些芯片放在哪里？**

→ PCB / substrate / carrier

**模块怎么从交换机获得电源和高速信号？**

→ electrical connector

**光怎么真正出去？**

→ fiber / optical connector / FAU / lens / coupling structure

**整个东西怎么固定和散热？**

→ housing / heatsink / TIM

于是才从：

```text
DSP
Driver
EML
PD
TIA
```

扩展成比较完整的产品构成：

```text
Electronic:
- DSP
- Driver
- TIA
- PMIC / MCU / EEPROM等
- PCB

Optical:
- EML
- PD
- lens/coupling optics
- FAU / fiber
- optical connector

Mechanical / Thermal:
- housing
- heatsink
- TIM

Interface:
- electrical connector
```

这里有一个非常重要的方法：

> **信号链告诉我核心功能器件；产品形态告诉我还缺哪些支撑件。**

---

### 第六步：用真实成品规格反查，避免“脑补器件”

我最后会拿这个结构重新去对真实模块资料。

例如 Coherent 800G DR8 datasheet 能直接确认：

- transmitter：EML
- receiver：PIN
- connector：Dual MPO12
- single-mode fiber
- 3.3V supply
- digital diagnostics citeturn369980search1

而 Coherent 800G DR4 又确认：

> electrical side 是 8×100G，optical side 是 4×200G EML。citeturn369980search2

Lumentum则从器件侧确认：

> EML内部是 DFB + EAM。citeturn369980search7

所以我不是期待某一份资料给我：

> “完整光模块有12个部件。”

而是把不同层级资料拼起来：

```text
模块厂
→ 告诉我模块规格和Tx/Rx技术

器件厂
→ 告诉我EML/PD内部是什么

IC厂
→ 告诉我DSP/Driver/TIA

封装/设备资料
→ 告诉我实际物理布局和连接

标准/MSA
→ 告诉我接口、lane、form factor
```

这就是**cross-source reconstruction**。

---

## 所以第一轮真正的搜索方法，不是搜一句话

不是：

`What are optical modules made of?`

而是分六组搜索。

| 我要解决的问题 | 我会搜什么 |
|---|---|
| 找代表产品 | `800G DR4 EML OSFP datasheet` |
| 确认Tx/Rx | `800G EML transmitter PIN receiver` |
| 看EML内部 | `200G EML DFB EAM datasheet` |
| 补电子链路 | `800G transceiver DSP driver TIA` |
| 补光路 | `EML fiber coupling FAU lens transceiver` |
| 补产品结构 | `800G optical transceiver teardown PCB optical engine` |

而且优先使用**原始资料**。

### 第一优先：成品厂商

Coherent、Lumentum、Cisco、Arista等。

解决：

> “现实产品到底用了什么？”

### 第二优先：核心器件厂

Lumentum、Coherent、Marvell、Broadcom等。

解决：

> “这些东西到底是什么？”

### 第三优先：标准 / MSA

IEEE、OSFP MSA、QSFP-DD MSA。

解决：

> “模块外部接口和lane结构是什么？”

### 第四优先：设备厂application

ASMPT、Besi等。

解决：

> “这些部件现实中怎么摆、怎么封装？”

论文更多用于：

> **解释原理和工艺，而不是判断市场上哪种产品最主流。**

---

## 最核心的研究公式

第一轮实际上只需要这个：

> **Function → Component → Interface → Physical product → Source validation**

具体到光模块：

```text
光模块做什么？
↓
电 ↔ 光

需要哪些功能？
↓
处理 / 驱动 / 发光调制 / 耦合 / 探测 / 放大

什么器件完成？
↓
DSP / Driver / EML / FAU / PD / TIA

它们能直接连吗？
↓
检查interface，补漏掉的器件

它们怎么成为一个产品？
↓
PCB / connector / housing / thermal

真实产品真这么做吗？
↓
datasheet + component datasheet + standards交叉验证
```

所以，**我第一轮最应该做但当时没有做好的，是先选 reference product，再开始拆。** 当时直接从一般性“光模块”出发，所以把 SiPh 也放进了第一版构件列表；你后来追问“硅光是不是最主流”，才迫使我们把这个方法修正为现在更严谨的版本。

有。回看目前几轮讨论，**至少有几处我把“合理的工程假设/典型实现”说得过于像普遍事实**。需要纠正。

## 1. 最明显的一处：把硅光模块当成“最主流代表”

我最初说：

> “典型 800G/1.6T 可插拔光模块，可以用 SiPh + CW Laser 作为参考模型。”

这里的问题是，我实际上做了一个未经验证的假设：

> **“硅光 = 当前最具代表性的主流结构。”**

这不是可以直接成立的事实。

后来核查后，我们修正为：

- EML 和 SiPh 都是当前高速数据中心光模块的重要路线；
- 不能简单说 SiPh 已经取代 EML；
- 如果目的是建立一个“传统高速光模块拆解基准”，用 **800G EML 可插拔模块**作为 reference design 更容易讲清楚。

这一处属于明确的**假设被我说成了事实倾向**。

---

## 2. “800G EML 模块由这些部件组成”——其中一部分是基准架构，不是所有产品的固定 BOM

后来我给出了：

> DSP + Driver + EML + PD + TIA + FAU + PCB + Housing + Heat Sink……

这个作为**教学用 reference architecture**是合理的，但如果把它说成：

> “800G EML 光模块一定由这些独立部件组成”

就不严谨。

原因是实际产品中可能发生集成：

- Driver 可能与其他 EIC 高度集成；
- TIA 可能是独立 die，也可能与 receiver assembly 更紧密集成；
- PD 数量、形式与具体 DR4/DR8/FR4 架构有关；
- 光路可能使用独立 lens，也可能不以我们图里的形式存在；
- FAU、lens、coupler 的具体实现依赖封装架构；
- PMIC、MCU、EEPROM 的集成形式也会变化。

所以正确标记应该是：

> **“一个合理的典型 BOM / reference architecture”**

而不是：

> **“行业统一 BOM”。**

---

## 3. “Driver → EML = Wire Bond / Flip Chip”说得太确定

这一点也需要修正。

我之前写：

> Driver → EML：Wire Bond / Flip Chip

正确表达应该是：

> **Driver 与 EML 之间需要非常短的高速电互连；具体实现可能包括 wire bond、flip-chip、基板互连或其他共封装方式，取决于产品设计。**

也就是说：

**需要高速电互连**是事实。

但：

**一定由 Wire Bonder 或 Flip Chip Bonder完成**

不是普遍事实。

我当时实际上是从常见封装工艺反推设备，而没有针对某一个具体 800G 模块的 teardown / manufacturing flow 验证到底是哪种方式。

因此这一部分属于：

> **工程上合理，但产品级证据不足。**

---

## 4. “EML → Lens → FAU → Fiber”也属于典型光路，不是固定结构

之前为了教学，我画成：

```text
EML
↓
Lens
↓
FAU
↓
Fiber
```

这个图非常容易理解，但容易造成一个错误印象：

> 每一个 EML 模块里面都一定存在一个独立 Lens，然后连接 FAU。

事实没有这么统一。

不同设计可能使用不同的：

- free-space coupling
- lens system
- butt coupling
- fiber array arrangement
- optical subassembly
- passive/active alignment scheme

所以真正确定的是：

> **EML输出的光最终必须高效率地耦合到光纤。**

而：

> **中间具体经过哪些独立光学件**

属于设计变量。

因此在正式报告中，我建议把图改成：

```text
EML
↓
Optical coupling structure
↓
Fiber / FAU
```

然后在旁边注明：

> Optical coupling structure *may include lens, isolator, FAU and other micro-optics depending on design.*

这样严谨很多。

---

## 5. “PD → TIA 必须非常靠近”基本正确，但“怎么靠近”是推断

这一条需要区分。

### 比较可靠的工程事实

高速接收链中：

> PD输出信号很弱，PD与TIA之间的寄生电容、电感和噪声会影响带宽和灵敏度，因此高速设计倾向缩短 PD–TIA 电连接。

这是扎实的工程原则。

### 我进一步说：

> 因此需要 Die Bonder + Wire Bonder / Flip Chip Bonder。

这里已经跨了一步。

正确逻辑应该是：

```text
PD–TIA需要低寄生、短互连
↓
设计通常要求紧密集成
↓
可能使用特定die attach / wire bond / flip chip / integrated receiver方案
```

必须看到具体 receiver assembly 才能判断实际设备。

所以：

> **“需要短互连”是事实；“一定使用哪台设备”属于待验证制造方案。**

---

## 6. “PCB 是整个模块的骨架”是教学比喻，不是严格工程定义

我之前说：

> PCB其实是整个模块的“骨架”。

这句话作为教学比喻可以，但如果用于产业研究，最好不要当严格事实。

传统 pluggable module 的确大量电子器件安装/连接于 PCB 上。

但是随着：

- optical engine
- ceramic substrate
- interposer
- flex
- SiPh package
- CPO

等架构发展，PCB并不一定承担所有器件的主要物理承载作用。

所以更准确的是：

> **在典型可插拔模块中，PCB是主要电子互连与器件承载平台之一。**

而不是“所有光模块的骨架”。

---

## 7. 我对“制造设备”的列表里有一些是“工艺族推断”，而不是逐项产品验证

例如我写：

> EML：MOCVD → 光刻 → ICP/RIE → PECVD → PVD → Cleaving → Facet coating……

这套工艺方向整体是合理的。

但这里应该分三种证据强度：

### A. 高置信度

例如：

- InP / III-V 外延需要 epitaxy；
- EML需要形成 DFB/EAM 等结构；
- 需要 patterning / etching / metallization；
- laser facet涉及 cleaving / coating；
- 最后需要 optical/electrical test。

### B. 一般性工艺推断

例如具体某一步：

> 用 PECVD 还是其他 dielectric deposition；
> 用某类 ICP/RIE recipe；
> 某具体层使用蒸镀还是 sputter。

这些取决于厂商工艺。

### C. 厂商专有信息

具体：

- recipe
- layer stack
- tool model
- process sequence
- yield control

没有厂商资料/论文/fab资料不能断言。

我之前把 A+B 混在同一列表里，导致读者容易认为：

> **每家 EML 厂都是完全这一条流程。**

这不够严谨。

---

# 8. “DSP / Driver / TIA = CMOS/SiGe”也应该更谨慎

我之前将：

- DSP → CMOS
- Driver/TIA → CMOS / SiGe

作为概括。

DSP 使用先进 CMOS 是非常合理的主流判断。

但 Driver / TIA 的工艺平台存在变化，具体可以是：

- CMOS
- SiGe BiCMOS
- 其他高速电子工艺

因此不能在没有具体器件型号情况下说：

> 某颗800G Driver就是SiGe。

应该写：

> **高速 Driver/TIA 可采用 CMOS、SiGe BiCMOS 等工艺，具体取决于产品。**

---

# 哪些目前我认为可以继续当作“硬事实骨架”？

下面这些相对稳固：

```text
光模块的基本任务：

Electrical → Optical
Optical → Electrical
```

因此一个直接检测高速光模块原则上必须解决：

```text
TX:
高速电信号处理
→ 驱动/调制
→ 光产生/调制
→ 光纤耦合

RX:
光纤耦合
→ 光探测
→ 电信号放大
→ 高速电信号处理
```

对于我们选择的 **EML reference architecture**，核心功能器件可以合理表示成：

```text
Tx:
DSP → Driver → EML → optical coupling → fiber

Rx:
fiber → optical coupling → PD → TIA → DSP
```

再加上：

```text
PCB / electrical interface
Power management / control
Mechanical structure
Thermal management
```

这个框架我认为可以继续使用。

关键是给它贴正确标签：

> **Reference architecture**

而不是：

> **所有800G光模块的唯一结构。**

# 我建议从现在开始给你的研究加一个证据等级

后面我们每拆一个部件，都标：

| 标签 | 含义 |
|---|---|
| **F — Fact** | 厂商datasheet、标准、论文或明确原始资料确认 |
| **T — Typical** | 行业常见实现，但不是所有产品都如此 |
| **I — Inference** | 根据物理/工程约束推导出的合理判断 |
| **U — Unknown** | 需要具体产品 teardown / 专利 / 厂商资料才能确认 |

例如：

| 判断 | 等级 |
|---|---|
| EML集成激光器和电吸收调制器 | **F** |
| 800G EML模块存在DSP、driver、receiver链 | **F/T** |
| 某具体模块Driver通过wire bond连接EML | **U，除非找到证据** |
| PD和TIA应缩短高速电连接 | **F/I** |
| 某厂采用ASMPT某型号die bonder | **U，必须单独验证** |

这会显著降低我们后面研究设备公司时犯错的概率。

**所以答案是：有。最主要的问题不是基础物理逻辑错，而是我曾把“典型架构”和“工程上合理的制造实现”表达成了好像所有产品都如此。** 后面最需要警惕的正是这一点，尤其当我们开始从工艺映射到具体设备厂商时，推断风险会进一步放大。
